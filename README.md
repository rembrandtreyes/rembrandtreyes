## Open source

- **[Job Hunt HQ](https://github.com/rembrandtreyes/jobhunt-hq)**: a job-search command center that runs on your own machine. One Go binary, one page, and your data in a SQLite file. No accounts, no cloud.
- **[Ariadne](https://github.com/rembrandtreyes/ariadne)**: a deterministic call graph for your whole codebase, served to agents over MCP and LSP in under 5 ms. Written in Rust and shipped as a single static binary.
- **[Senna](https://github.com/rembrandtreyes/senna)**: my Claude Code harness, packaged as a plugin marketplace. Every project gets the same guardrails, hooks, agents, and review workflow.
